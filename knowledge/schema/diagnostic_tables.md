# Diagnostic / audit / integration tables

Generated by `tools/schema_catalog/build.py` from the SSDT projects (EU = superset, APAC subset). Column lists are exact (parsed from CREATE TABLE). Join hints in the first line of each table are curated; "auto join candidates" are derived from column names. Row data is not in the SSDT projects.

## How to correlate with a Work Order

1. Direct id: tables with `WorkOrderId` -> `Operation.WorkOrder.Id` (e.g. Log.WorkOrderJsonLog, Operation.WorkOrderGpsInfo).
2. Key/Value style tables (Log.RESTEntries, Gateway.*): the work order id is in a key column or inside the request/response text.
3. Error log: `Log.DB_Errors.ErrorMessage LIKE 'WOId:%<id>%'` (procedures put `WOId:<id>` in the message when calling Util.AddErrorLog), then narrow with `ErrorDateTime` and `ErrorProcedure`.
4. Always filter by `TenantId` where the table has it (multi-tenant DB).
5. Status names: `Catalog.Status.AppTranslationId` + `LanguageId` -> `Catalog.AppTranslationEntry.FieldText`.
